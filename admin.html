Step-by-Step Search Engine Submission Guides
Follow these simple steps to register and index your website on every major global search engine.
  • Google Search
  • Bing & Yahoo

Google Search Console Submission (85%+ Global Search Share)
Open Google Search Console
  1. Visit Google Search Console and log in with your Google account.
  2. Click Add Property and enter your public domain (e.g. https://yourdomain.com).
  3. Select HTML Tag verification method. Copy the verification code and paste it into the <meta name="google-site-verification" content="..."> tag in index.html (or upload the HTML verification file to your website root).
  4. Once verified, click on Sitemaps in the left sidebar.
  5. Under "Add a new sitemap", type: sitemap.xml and click Submit.
  6. Google will display a green "Success" badge. Googlebot will crawl and index your blood bank within 24 to 48 hours.
Microsoft Bing & Yahoo Search Webmaster Tools
Open Bing Webmaster Tools
2-in-1 Indexing: Submitting to Microsoft Bing automatically submits and indexes your website on Yahoo Search, because Yahoo is powered by the Bing search index!
  1. Visit Bing Webmaster Tools.
  2. Click Import from Google Search Console for instant 1-click verification, OR add your site URL manually.
  3. Go to Sitemaps ➔ Click Submit Sitemap ➔ Enter https://yourdomain.com/sitemap.xml.
  4. Bingbot will crawl your pages and list them in search results across Bing, Yahoo, and Windows Search.
DuckDuckGo Search Discovery

DuckDuckGo does not have a separate manual submission form. Instead, DuckDuckGo uses a hybrid crawler network:

  • Primary Source (Bing Index): Once your website is submitted to Bing Webmaster Tools, DuckDuckGo automatically pulls and indexes your site within a few days.
  • DuckDuckBot Crawler: DuckDuckGo's official web crawler follows links from robots.txt and sitemap.xml. Both are pre-configured to welcome DuckDuckBot.
  • Action required: Complete the Bing Webmaster Tools submission above, and DuckDuckGo will index your blood bank automatically!

Step 1: The 3 Required Certificate Files
A full enterprise SSL/TLS installation requires all three pieces of text data correctly applied to the server.
  • 1. Certificate (CRT)
  • 2. Private Key (KEY)
  • 3. CA Bundle (CABUNDLE)
  • Combined Chain (PEM)
Primary Server Certificate File: ssl/certificate.crt | Type: X.509 PEM | Key: RSA 2048-bit

Description: Usually named yourdomain.crt or certificate.crt. This public certificate binds the cryptographic public key to your website identity and domain name.

Confidential Private Key File: ssl/private.key | Format: PKCS#8 RSA | Strength: 2048-bit
Strict Backend Security Rule: This private key text block was generated at the very beginning when you created your Certificate Signing Request (CSR). It stays strictly on the server and is never transmitted to the browser or public visitors.
Intermediate Trust Authority File: ssl/ca_bundle.crt | Issuer: LifeFlow Global Root CA
Crucial for a Full Installation: The CA Bundle chains your certificate back up to a trusted global root authority. Skipping this file will trigger "Not Trusted" security warnings on mobile phones and specific modern browsers.
Full Certificate Chain Bundle File: ssl/server_bundle.pem | Combined CRT + Intermediate CA

Description: Pre-combined single file containing both your Server Certificate (CRT) and the CA Bundle. Used by Nginx, HAProxy, and cloud load balancers.

cPanel Complete SSL/TLS Installation Steps:
  1. Log in to your hosting provider account and open cPanel.
  2. Scroll to the Security section and click on SSL/TLS.
  3. Click on Manage SSL Sites (under "Install and Manage SSL for your website").
  4. Select your Domain Name from the drop-down menu.
  5. Paste your files into the designated text fields:
    • Paste the Certificate (CRT) content into the Certificate (CRT) box.
    • Click Autofill by Domain next to it; this will usually retrieve your Private Key automatically. If not, paste the key manually.
    • Paste the Certificate Authority Bundle (CABUNDLE) into the final text area.
  6. Click Install Certificate. cPanel will confirm with a green success message: "SSL Host Successfully Installed".
  7. Enable HTTPS Redirection toggle in cPanel Domains list to automatically force all HTTP traffic to HTTPS.
Apache Server VirtualHost & .htaccess Configuration

Add this block inside your Apache httpd-ssl.conf or site configuration file: 

<VirtualHost *:443>
    ServerName localhost
    DocumentRoot "C:/path/to/bloodbank-html"

    SSLEngine on
    SSLCertificateFile    "ssl/certificate.crt"
    SSLCertificateKeyFile "ssl/private.key"
    SSLCACertificateFile  "ssl/ca_bundle.crt"

    # Enterprise Security Headers
    Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
    Header always set X-Content-Type-Options "nosniff"
    Header always set X-Frame-Options "SAMEORIGIN"
</VirtualHost>
Active .htaccess (Installed in Project Root)

Forces permanent 301 HTTPS upgrade and blocks unauthorized directory scanning: 

RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

# Security Headers
<IfModule mod_headers.c>
    Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
    Header always set X-Content-Type-Options "nosniff"
    Header always set X-Frame-Options "SAMEORIGIN"
    Header always set X-XSS-Protection "1; mode=block"
</IfModule>

# Block direct access to SSL private keys and configuration
<FilesMatch "\.(key|pem|crt)$">
    Require all denied
</FilesMatch>
Nginx SSL Server Block

Place the combined bundle server_bundle.pem and private.key in your Nginx configuration: 

server {
    listen 80;
    server_name localhost;
    return 301 https://$host:8443$request_uri;
}

server {
    listen 8443 ssl http2;
    server_name localhost;

    ssl_certificate     ssl/server_bundle.pem; # CRT + CA Bundle combined
    ssl_certificate_key ssl/private.key;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers on;

    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains; preload" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;

    root /path/to/bloodbank-html;
    index index.html;
}
